# dan9zpam Homebrew Tap

Official Homebrew tap for apps and utilities by [dan9zpam](https://github.com/dan9zpam).

## Installation

To install **Claude Limits Bar** (macOS Menu Bar app):

```bash
brew install --cask dan9zpam/tap/claudelimitsbar
```

Or add the tap first:

```bash
brew tap dan9zpam/tap
brew install --cask claudelimitsbar
```

To update in the future:
```bash
brew upgrade claudelimitsbar
```

## Available Casks
- **`claudelimitsbar`**: [Claude Limits Bar](https://github.com/dan9zpam/ClaudeLimitsBar) — Claude Code and Google Antigravity (AGY) limits, usage analytics and an animated Clawd in your macOS Menu Bar. Formerly `agylimit` / `agylimits`: existing installs migrate on `brew upgrade`.
