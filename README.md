# dan9zpam Homebrew Tap

Official Homebrew tap for apps and utilities by [dan9zpam](https://github.com/dan9zpam).

## Installation

To install **AGY Limits Bar** (macOS Menu Bar app):

```bash
brew install --cask dan9zpam/tap/agylimit
```

Or add the tap first:

```bash
brew tap dan9zpam/tap
brew install --cask agylimit
```

To update in the future:
```bash
brew upgrade agylimit
```

## Available Casks
- **`agylimit`** / **`agylimits`**: [AGY Limits Bar](https://github.com/dan9zpam/AgyLimitsBar) — Real-time Google Antigravity (AGY) limits and quota tracker in your macOS Menu Bar.
